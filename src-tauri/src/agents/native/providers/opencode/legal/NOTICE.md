`anomalyco/opencode` GitHub release. OpenCode is distributed under the MIT
License; the adjacent `LICENSE` file contains the upstream license text.

OpenCode. Alfred does not grant that subscription, does not convert it to Zen
credit, and does not silently route requests to another provider or billing
owner.
