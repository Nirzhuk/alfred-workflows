# Code of Conduct

Alfred's community should be useful, welcoming, and safe for everyone.

## Expected behavior

- Be respectful, patient, and specific.
- Critique ideas and code without attacking people.
- Assume good intent while accepting correction when impact differs from
  intent.
- Respect privacy and remove sensitive data from examples, logs, and images.
- Give credit and honor licenses when using someone else's work.
- Help keep discussions focused on improving the project.

## Unacceptable behavior

Harassment, threats, discrimination, sexualized attention, deliberate
intimidation, doxxing, sustained disruption, and publishing another person's
private information are not tolerated. Neither is using project spaces to
promote malware, credential theft, deceptive builds, or other harm.

## Scope and enforcement

This policy applies in repository discussions, reviews, community spaces, and
when someone publicly represents the project. Report conduct concerns privately
to the maintainers through the repository owner's GitHub profile. Do not open a
public issue when doing so would expose a target or sensitive evidence.

Maintainers may edit or remove content, reject contributions, temporarily limit
participation, or permanently ban someone when necessary to protect the
community. They will aim to consider context, impact, and patterns of behavior
and will keep reports as confidential as practical.
